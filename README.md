# ReachInbox Email Scheduler

Full-stack email scheduling system built for the ReachInbox Software Development Intern Assignment.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma

### Infrastructure
- PostgreSQL
- Redis
- BullMQ
- Docker

### Email
- Nodemailer
- Ethereal Email
